# 原命连携 / 命定终结技

> 本文档介绍 TCDEX（原命）原创核心机制：**元素连携 + 命定终结技**。
>
> 该机制在“原神式元素反应”和“命运2 式光等 / 武器 / 技能循环”的基础上，尝试形成属于“原命”自己的战斗语言。

---

## 1. 机制定位

原命连携不是替代现有元素反应，而是把现有的：

- 元素攻击
- 元素反应
- 元素残响
- 失衡/破绽
- 元素能量
- 超越
- 光等

串联成一套完整的玩家战斗循环。

核心循环如下：

```text
使用元素攻击
  ↓
积累连携链
  ↓
选择时机引爆连携
  ↓
根据连携元素数量触发：
  1-3 种 → 连携引爆
  4-5 种 → 元素风暴
  6+ 种 → 原命崩解
  ↓
敌人进入破绽
  ↓
发动命定终结技
  ↓
触发连携组合专属效果
  ↓
反哺元素能量 / 超越
```

## 2. 连携链

### 2.1 连携链结构

每个玩家拥有：

- **玩家主链**：记录玩家最近使用的元素行为。
- **目标准焦点链**：跟随当前攻击/准星目标，记录对该目标的元素使用。
- **群体连携溢出**：附近敌人身上存在不同元素残响时自动积累。

### 2.2 元素行为权重

不同元素行为对连携链的贡献不同：

| 行为 | 权重 |
|---|---|
| 元素武器普通攻击 | 1.0 |
| 元素技能 / 法术 | 1.5 |
| 元素爆发 | 3.0 |
| 触发元素反应 | 2.0 |
| 元素残响引爆 | 2.0 |
| 元素护盾破碎 | 3.0 |

### 2.3 连携链规则

- 链持续时间：**15 秒**。
- 重复元素只刷新对应节点时间，不新增链位。
- UI 显示完整时间线，计算档位只看“不同元素数量”。
- 脱战后自动清空主链。
- 切目标时焦点链自动跟随当前目标。

### 2.4 群体连携

- 玩家使用元素时，扫描附近敌人。
- 附近敌人身上存在不同元素残响时，自动连接并积累连携溢出。
- 群体连接只积累资源，不消耗敌人残响。

---

## 3. 连携引爆

### 3.1 触发条件

- 连携链非空。
- 不在引爆冷却中。

### 3.2 效果

- 清空主链、焦点链、群体溢出。
- 对周围敌人造成混合元素伤害。
- 把链上元素扩散到附近敌人。
- 给玩家自身施加 **10 秒连携增益**。
- 进入自然冷却。

---

## 4. 元素风暴

### 4.1 触发条件

连携链中不同元素数量为 **4 或 5** 时，连携引爆升级为元素风暴。

### 4.2 效果

- 持续 **5 秒**。
- 每 **10 tick** 对领域内敌人造成元素伤害并施加元素印记。
- 半径为 **6 格**。
- 终结技触发的元素风暴更强。

---

## 5. 原命崩解

### 5.1 触发条件

连携链中不同元素数量为 **6 种或以上**。

### 5.2 效果

- 大范围全元素爆发，半径 **8 格**。
- 对范围内敌人施加链中所有元素印记。
- 清除范围内元素残响。
- 生成“原命裂隙”，持续 **8 秒**。
- 裂隙每 10 tick 造成混合元素伤害并随机触发元素反应。

---

## 6. 命定终结技

### 6.1 触发条件

- 目标处于**破绽状态**。
- 玩家拥有连携链。
- 不在冷却中。

### 6.2 终结分档

| 不同元素数 | 终结技形态 |
|---|---|
| 1-3 | 普通连携终结 |
| 4-5 | 高级终结 + 元素风暴 |
| 6+ | 原命崩解 + 原命裂隙 |

### 6.3 终结后

- 消耗破绽窗口。
- 重置目标失衡值。
- 清空连携资源。
- 获得连携增益。
- 进入自然冷却。

## 7. 45 个二元连携组合专属效果

所有二元元素组合都拥有独立名称和效果类型。

| 类型 | 代表组合 |
|---|---|
| 伤害 | 烈日 + 水 → 蒸发 |
| 控制 | 冰影 + 水 → 冻结 |
| 增幅 | 电能 + 冰影 → 聚导体 |
| 护盾 | 虚空 + 落星 → 虚空结晶 |
| 扩散 | 虚空 + 罡流 → 虚空扩散 |
| 特殊 | 棱镜 + 月 → 月之暗面 |

### 效果优先级

```text
连携组合专属效果
  >
现有元素反应共鸣
  >
元素印记 / 基础扩散
```

### 组合效果数量限制

- 普通连携引爆最多应用 **2 个** 组合效果。
- 命定终结技最多应用 **3 个** 组合效果。
- 防止 4-5 种元素时所有效果同时叠加导致数值失控。

## 8. 与现有系统融合

### 元素能量
- 连携引爆 / 命定终结成功后反哺元素能量。
- 元素能量满时，连携与终结伤害自动提升。

### 超越
- 超越就绪或激活中时，连携与终结伤害自动提升。
- 连携引爆 / 终结也会为超越双槽充能。

### 光等
- 命定终结技会应用玩家攻击光等与目标怪物光等的光等差修正。

### 失衡 / 破绽
- 终结技基于现有失衡/破绽系统。
- 连携等级可强化或延长破绽窗口。
- 终结后消耗破绽并重置失衡。

## 9. 按键与 HUD

### 按键

| 按键 | 默认 | 作用 |
|---|---|---|
| 智能连携 | `C` | 自动选择终结技或连携引爆 |
| 连携引爆 | `R` | 强制发动连携引爆 |
| 命定终结 | `F` | 强制对焦点目标发动终结技 |

智能键逻辑：

```text
目标破绽 + 连携充足 → 命定终结技
否则 → 连携引爆
都不满足 → 不响应
```

### HUD

- 左上角 Buff HUD 显示：
  - 主链元素时间线
  - 焦点链
  - 连携增益剩余时间
  - 引爆冷却剩余时间

## 11. 技术实现

### 核心类

| 类 | 作用 |
|---|---|
| `PlayerChainCapability` | 玩家连携数据存储 |
| `ChainManager` | 连携积累、引爆、终结、融合逻辑 |
| `ChainAreaManager` | 元素风暴、原命裂隙 |
| `ChainComboEffects` | 二元组合专属效果执行 |
| `ComboEffectRegistry` | 45 个组合效果注册表 |
| `ChainActionPacket` | 客户端按键请求 |
| `ChainStateSyncPacket` | 服务端 → 客户端 HUD 同步 |
| `ChainKeybind` | 三个连携按键 |
| `ChainHud` | 客户端 HUD 缓存 |

### 事件接入

所有元素行为通过 `ElementCombatEvents` 统一上报：

- 元素武器攻击
- 元素技能 / 法术
- 元素爆发
- 元素反应
- 元素残响引爆
- 元素护盾破碎
